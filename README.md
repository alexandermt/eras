# Enterprise Ranking & Admissions System

This repository contains the code and resources for the Enterprise Ranking & Admissions System, built using FastAPI for the backend, React for the frontend, with data storage in MariaDB and Oracle ITS (read-only).

## Tech Stack
- **Backend:** FastAPI
- **Frontend:** React
- **Database:** MariaDB, Oracle (read-only)

## Installation & Setup
1. Clone the repository.
2. Install dependencies for both frontend and backend.
3. Set up your database credentials.
4. Run the applications.
